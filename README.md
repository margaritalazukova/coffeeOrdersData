## Introduction  
This coffee sales dashboard was created to help company's workers investigate coffee sales and ensure the right strategies are chosen.   
The data contains detailed information on orders information, customers information, sales, locations, products information.  
## Dashboard File  
My final dashboard is in [coffeeOrdersData.xlsx](https://github.com/user-attachments/files/31860325/coffeeOrdersData.xlsx)  


## Excel Skills Used   
The following Excel skills were utilized for analysis:   
1. XLOOKUP    
2. INDEX MATCH    
3. Formulas and Functions    
4. PivotTables and PivotCharts    
5. Data Formating   
6. Timeline, Slicers

## Coffee Sales Dataset   
The dataset used for this project cointains real-world data for coffee sales from 2019 to 2022. The dataset provides a foundation for analyzing data using Excel. It includes detailed information on:   
1. Orders
2. Customers
3. Products

1. **Multi-Criteria Lookup:** Retrieves product attributes from master table by matching Product ID from orders sheet against product database, returning corresponding Coffee Type, Roast Type, Size.
